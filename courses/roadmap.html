🎨 توسعه فرانت‌اند (Front-End)

محبوب‌ترین مسیر شروع
فرانت‌اند یعنی هر چیزی که کاربر می‌بیند و با آن تعامل دارد. این حوزه به هنر و خلاقیت نزدیک‌ترین حوزه برنامه‌نویسی است. هدف اصلی: ساختن تجربه کاربری روان، زیبا و سریع.
🔧 کتابخانه‌ها و فریمورک‌های اصلی
⚛️ React.js
محصول فیسبوک، قدرتمندترین کتابخانه برای ساخت UI. مبتنی بر کامپوننت، Virtual DOM، اکوسیستم عظیم (Next.js، Redux، React Native).
💚 Vue.js
فریمورک پیشرو و ساده، منحنی یادگیری ملایم، عملکرد عالی. Nuxt.js برای SSR، Pinia برای state management.
🅰️ Angular
محصول گوگل، فریمورک کامل با TypeScript، مناسب پروژه‌های سازمانی بزرگ.
🎨 Tailwind CSS
کتابخانه utility-first، طراحی سریع بدون خروج از HTML، سفارشی‌سازی عالی.
🎭 Bootstrap
کلاسیک و محبوب، Grid system عالی، مناسب MVP و ادمین پنل‌ها.
🔄 Redux / Zustand
مدیریت state در اپلیکیشن‌های بزرگ. Zustand سبک و ساده برای React.
✅ وظایف روزمره و چالش‌ها
  • پیاده‌سازی طراحی‌های UI/UX از Figma یا Adobe XD به کد
  • ساخت SPA با روتینگ سمت کلاینت
  • اتصال به REST API یا GraphQL
  • بهینه‌سازی عملکرد (Lazy Loading، Code Splitting)
  • سئو (SEO) با استفاده از SSR/SSG (Next.js، Nuxt)
  • تست واحد با Jest، React Testing Library
🛠️ ابزارهای مکمل
Webpack / ViteESLint / PrettierGit / GitHubFigmaChrome DevToolsStorybook

⚙️ توسعه بک‌اند (Back-End)

موتور محرک برنامه
پشت صحنه هر وب‌سایت و اپلیکیشن: مدیریت سرور، پایگاه داده، منطق کسب‌وکار، امنیت و APIها.
🗄️ زبان‌ها و فریمورک‌ها
🐍 Python + Django/Flask/FastAPI
ساده، قدرتمند، عالی برای ML و پروتوتایپ سریع.
🟢 Node.js + Express/Nest.js
جاوااسکریپت در سمت سرور، غیرهمزمان و رویدادمحور.
☕ Java + Spring Boot
استاندارد صنعت بانکی و سازمانی. امنیت بالا، عملکرد عالی.
🔷 Go (Golang)
هم‌روندی فوق‌العاده، محبوب در Docker، Kubernetes.
💎 Ruby on Rails
محبوب برای MVP، توسعه سریع.
🔷 .NET Core (C#)
محصول مایکروسافت، قدرتمند برای Enterprise.
💾 پایگاه‌های داده
🐘 PostgreSQL
پیشرفته‌ترین دیتابیس متن‌باز رابطه‌ای.
🐬 MySQL / MariaDB
محبوب و سریع، مناسب وردپرس، لاراول.
🍃 MongoDB
NoSQL مستندگرا، مقیاس‌پذیری افقی عالی.
⚡ Redis
ذخیره‌سازی در حافظه برای کش، نشست کاربر.

📱 برنامه‌نویسی موبایل

Native & Cross-Platform
اپلیکیشن‌هایی که توی جیب میلیاردها نفر قرار می‌گیرند. از اندروید و iOS گرفته تا کراس پلتفرم.
📲 Native Development (بومی)
🤖 Android - Kotlin
زبان رسمی گوگل برای اندروید. Jetpack Compose برای UI مدرن.
🍎 iOS - Swift
زبان امن و سریع اپل، SwiftUI جدید.
🔄 Cross-Platform (چندسکویی)
🦋 Flutter (Dart)
محصول گوگل، UI زیبا، Hot Reload، یک کد برای iOS، Android، Web.
⚛️ React Native
بر پایه React، استفاده از جاوااسکریپت، جامعه بزرگ.

🧠 یادگیری ماشین و Deep Learning

🔥 PyTorch
