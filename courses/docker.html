📦 مفاهیم پایه داکر

ایمیج (Image)
قالب فقط خواندنی شامل کد، runtime، کتابخانه‌ها و وابستگی‌ها. مثل یک الگو یا snapshot.
کانتینر (Container)
نمونه اجرایی از یک ایمیج. هر کانتینر ایزوله و سبک است و با یک دستور اجرا می‌شود.
داکر هاب (Docker Hub)
رجیستری عمومی برای ذخیره و به اشتراک‌گذاری ایمیج‌ها (مثل گیت‌هاب برای داکر).
داکر فایل (Dockerfile)
فایل متنی حاوی دستورالعمل‌های ساخت ایمیج سفارشی.
جلدها (Volumes)
ذخیره‌سازی دائمی داده‌ها مستقل از چرخه عمر کانتینر.
شبکه (Network)
ارتباط بین کانتینرها؛ انواع bridge, host, none, overlay.
🐳 تفاوت کانتینر با ماشین مجازی: کانتینرها کرنل سیستم عامل میزبان را به اشتراک می‌گذارند → حجم کم (مگابایت)، راه‌اندازی سریع (چند میلی‌ثانیه).
⚙️ پیش‌نیاز: داکر را از docker.com نصب کنید. برای لینوکس از sudo apt install docker.io.

🐚 دستورات ضروری داکر

📋 جدول خلاصه دستورات داکر

🔁 جریان کاری معمول (Development Workflow)

1️⃣ docker pull nginx ← دریافت ایمیج از داکرهاب
2️⃣ docker run -d -p 8080:80 --name myweb nginx ← اجرای کانتینر وب سرور
3️⃣ docker ps ← بررسی کانتینرهای در حال اجرا
4️⃣ ایجاد Dockerfile و ساخت ایمیج سفارشی: docker build -t myapp .
5️⃣ docker push myusername/myapp ← ارسال به داکرهاب
🌐 برای اپلیکیشن چند سرویس: docker-compose up -d

🎓 با تمرین عملی روی دستورات، به یک متخصص داکر تبدیل شوید.
