مفاهیم پایه

مخزن (Repository)
محل ذخیره تمام نسخه‌ها و تاریخچه پروژه. دو نوع: محلی (روی کامپیوتر) و ریموت (روی گیت‌هاب).
کامیت (Commit)
ثبت یک نسخه جدید با پیام توضیحی. هر کامیت یک شناسه یکتا دارد.
مرحله آماده‌سازی (Stage)
محلی برای جمع‌آوری تغییرات قبل از کامیت. با git add فایل‌ها را به Stage می‌بریم.
شاخه (Branch)
خط توسعه جداگانه. شاخه اصلی معمولاً main یا master است.
💡 نکته مهم: قبل از هر کاری حتماً این دو دستور را برای معرفی هویت خود اجرا کنید:
git config --global user.name "نام شما"
git config --global user.email "ایمیل شما"

جدول خلاصه دستورات مهم

🔁 جریان کاری معمول روزمره

1️⃣ git status ← بررسی وضعیت و مشاهده نمادها
2️⃣ git add . ← اضافه کردن همه تغییرات به Stage
3️⃣ git commit -m "پیام مفید" ← ثبت نسخه جدید
4️⃣ git push ← ارسال به گیت‌هاب
➕ برای دریافت تغییرات دیگران: git pull
🌿 برای ساخت شاخه جدید: git checkout -b name-feature
